# 全站雾蓝编辑台视觉改造

## 目标

将首页、分镜脚本工作台、小说正文、资产库、历史作品和分镜视频生成页统一为雾蓝编辑台风格，同时保持全部页面行为、路由、字段、接口与导航不变。

## 视觉系统

- 页面背景：冷白 `#f4f7fb`。
- 内容面板：白色与雾蓝浅层 `#edf3f8`。
- 主文字：深蓝灰 `#1f2d3d`；辅助文字：`#617182`。
- 唯一强调色：青蓝 `#177e9f`，仅用于主操作、选中状态和键盘焦点。
- 形状：面板 12px、控件 8px、标签 999px。
- 动效：仅使用 160ms 悬停与按下反馈，并遵从浏览器的减少动态效果偏好。

## 页面策略

1. 所有页面使用 `studio-theme` 主题类，统一导航、按钮、表单、面板和空状态。
2. 首页与分镜工作台突出输入和继续创作入口。
3. 正文页突出阅读器、章节目录和右侧分镜辅助区。
4. 资产库突出筛选、列表和详情的三栏层级。
5. 历史页采用更紧凑的作品列表层级。
6. 视频生成页保留现有制作控制台分区，改为雾蓝主题而不改变首帧和视频工作流。

## 约束与验收

- 不更改 URL、导航文本、元素 ID、`data-action`、`data-role` 或 API 地址。
- 静态前端测试继续覆盖既有交互钩子，并断言所有页面具备主题类。
- 运行前端静态测试、Maven 全量测试和 `git diff --check`。

# 分镜视频生成控制台视觉改造

## 目标

在不改变路由、接口、按钮动作、字段或生成流程的前提下，重新组织分镜视频生成页的视觉层级与信息密度，使创作者可以更快完成脚本查看、首帧选择和视频生成。

## 设计方向

- 受众：连续处理多个分镜的创作者。
- 风格：深石墨工作台，暖灰内容层，琥珀色为唯一强调色。
- 设计参数：`DESIGN_VARIANCE 4`、`MOTION_INTENSITY 2`、`VISUAL_DENSITY 8`。
- 圆角规则：面板 12px，控件 8px，状态标签为圆角胶囊。

## 保留项

- 保持 `/video-generation.html`、现有导航文本和页面元素 ID 不变。
- 保持所有 `data-action`、`data-role`、请求地址、上传控件、事件绑定和状态文案的业务含义不变。
- 保持分镜可展开、首帧双击预览、参考资产移除、视频历史与安全改写重试功能不变。

## 交互与布局

1. 页面顶部使用章节概览条，明确当前章节、分镜数量、总时长与返回操作。
2. 每张分镜卡片的摘要行显示序号、时长、景别和当前任务状态；展开按钮保持原生 `details` 语义。
3. 展开内容分为脚本区、参考资产区和生成控制区。脚本区优先占据阅读宽度，参考资产区在桌面端占较窄栏位。
4. 生成控制区将分辨率、首帧操作和视频操作分组；生成视频是唯一高强调主按钮。
5. 窄屏下各区域变为单列，按钮允许换行且不遮挡上传控件。

## 验收标准

- 静态前端测试覆盖新的语义结构和既有动作钩子。
- 现有 `video-generation-page.test.js` 通过。
- Maven 全量测试通过。
- `git diff --check` 不报告空白错误。

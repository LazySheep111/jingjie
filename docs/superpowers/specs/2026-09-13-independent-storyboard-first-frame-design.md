# 独立分镜首帧设计

## 目标

将分镜首帧生成从视频生成任务中拆出。用户可为每个分镜多次生成并保留首帧候选图，手动选择其中一张后再提交视频生成。视频生成失败不会要求重新生成首帧。

## 已确认的产品规则

- 每次点击“生成分镜首帧”仅生成一张图片。
- 首帧版本数量不限；所有未删除版本都显示在对应分镜下。
- 用户点击首帧缩略图即可选中，选中态仅存在当前页面会话；刷新页面后必须重新选择。
- 未选中首帧时点击“生成视频”，页面提示“请先选择首帧”，不创建视频任务。
- 同一分镜的首帧任务彼此互斥，视频任务彼此互斥；首帧任务与视频任务可以并行。
- 视频生成失败后保留当前页面选中的首帧；“重试生成视频”继续使用该首帧。
- 每张首帧有删除操作。删除为逻辑删除：从候选列表移除且不可再选，但保留物理文件和历史视频快照，保证已生成视频不受影响。

## 架构

新增 `storyboard_first_frame` 作为首帧候选和首帧异步任务的唯一记录。它负责首帧的版本、生成状态、图片路径、提示词快照、风格快照、错误信息及逻辑删除状态。

视频任务不再调用首帧生成器。创建视频任务时，客户端传入 `firstFrameId`；服务端验证该首帧属于当前小说、章节和分镜且未删除，然后把 `firstFrameId` 与图片路径写入视频任务快照。后续重试直接使用任务快照中的首帧，不依赖页面选择状态。

## 数据模型

新增表 `storyboard_first_frame`：

- `id`：首帧 ID。
- `novel_id`、`chapter_num`、`storyboard_scene_id`：归属范围。
- `version`：同一分镜内递增版本号。
- `status`：`QUEUED`、`GENERATING`、`SUCCESS`、`FAILED`。
- `image_path`：生成成功后的本地 Web 路径。
- `prompt_snapshot`、`style_snapshot`：生成时的分镜提示词和全书视觉风格快照。
- `error_message`：失败原因。
- `is_deleted`：逻辑删除标记。
- `create_time`、`update_time`：审计时间。

在 `video_generation_task` 增加可空的 `first_frame_id`。保留已有 `first_frame_path` 作为不可变的路径快照，供任务轮询、失败重试及视频历史使用。

## 后端接口

- `POST /api/novel/{novelId}/chapters/{chapterNum}/storyboard/{sceneId}/first-frame-tasks`：创建单张首帧异步任务。
- `GET /api/first-frame-tasks/{taskId}`：获取首帧任务状态。
- `GET /api/novel/{novelId}/chapters/{chapterNum}/storyboard/{sceneId}/first-frames`：列出未删除首帧，按版本倒序。
- `DELETE /api/storyboard-first-frames/{firstFrameId}`：逻辑删除首帧。
- 现有创建视频任务接口请求体新增 `firstFrameId`；缺失、跨分镜或已删除时返回明确校验错误。

首帧生成继续使用既有 `StoryboardFrameGenerator`、分镜信息、人物/场景三视图和全书视觉风格；只改变任务边界，不改变生成提示词来源。

## 页面交互

每个分镜卡片操作区依次放置“生成分镜首帧”“生成视频”“查看视频历史”。

首帧区域展示缩略图网格：

- 生成中的首帧显示加载状态。
- 成功首帧可点击选择，选中项以高亮边框和“已选中”标记显示。
- 每张成功首帧可删除；删除后立即从列表和可选范围移除。
- 视频任务进行中时仅禁用“生成视频”，避免同一分镜重复提交视频任务；用户仍可生成新的首帧候选图。
- 首帧任务进行中时仅禁用“生成分镜首帧”；已有首帧仍可选择并用于生成视频。

## 错误处理

- 首帧生成失败：任务状态显示失败与服务端错误；用户可再次点击“生成分镜首帧”获得一个新的版本。
- 视频生成失败：保留页面选中首帧和任务中的首帧快照；重试不重新生成图片。
- 首帧不存在、归属不匹配或已删除：服务端拒绝视频任务并返回“请选择当前分镜的有效首帧”。
- 逻辑删除后不删除本地文件，视频记录中已保存的 `first_frame_path` 可继续访问。

## 测试范围

- Mapper 参数绑定和版本递增。
- 首帧任务创建、异步成功/失败状态、列表过滤逻辑删除。
- 视频任务必须接收有效首帧，且失败重试复用任务快照。
- 控制器路由与输入校验。
- 视频页静态检查：首帧按钮、缩略图选择、未选首帧提示、删除操作和运行态禁用。

## 非目标

- 不提供首帧提示词手工编辑。
- 不自动选择“最新首帧”。
- 不在本期物理清理逻辑删除的首帧文件。
- 不改变 MiniMax 视频模型、Seedream 首帧模型或既有视频历史数据。

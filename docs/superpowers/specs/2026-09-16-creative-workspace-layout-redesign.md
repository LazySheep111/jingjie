# 创作工作台布局重构

## 目标

在保留所有功能、接口、字段与操作入口的前提下，将全站从统一换肤升级为按创作任务组织的工作台界面。

## 设计系统

- 视觉语言：雾蓝编辑台，冷白画布、雾蓝结构层、深蓝灰文字、青蓝主操作。
- 参数：`DESIGN_VARIANCE 5`、`MOTION_INTENSITY 2`、`VISUAL_DENSITY 7`。
- 规则：面板仅用于明确的工作区，数据列表使用行、画廊或检查器，而非重复的等宽卡片。

## 页面结构

1. 首页：创作概览头部，左侧小说设定，右侧大纲输出和章节进度。
2. 分镜工作台：导入命令面板和紧凑的最近作品项目列表。
3. 正文页：固定章节导航、主阅读编辑器、右侧创作辅助停靠区。
4. 资产库：筛选导航、资产画廊、详情检查器三栏结构。
5. 历史页：作品项目列表，突出标题、类型、更新时间和继续创作操作。
6. 视频页：保留现有脚本、资产、首帧和视频控制流程，增强阶段分区与操作优先级。

## 保护范围

- URL、导航文本、元素 ID、`data-action`、`data-role`、文件上传和 API 请求全部保持不变。
- 动态渲染函数继续使用既有数据字段，只允许添加语义容器或类名。
- 窄屏下所有多栏布局收拢为单列，导航可横向滚动。

## 验收

- 前端静态测试验证新增的主要工作区类，以及原有业务钩子。
- 全部前端静态测试、`mvn test` 与 `git diff --check` 均通过。

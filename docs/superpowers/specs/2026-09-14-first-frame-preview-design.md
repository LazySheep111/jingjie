# 分镜首帧大图预览设计

## 目标

在视频生成页面查看既有分镜首帧时，用户可以放大图片检查细节，同时保留现有的首帧选择流程。

## 交互

- 单击首帧缩略图：选中该首帧，供后续生成视频使用。
- 双击同一首帧缩略图：打开大图预览，不改变当前选中的首帧。
- 预览使用模态弹窗，图片按原始比例在视口内完整显示。
- 用户可通过关闭按钮、点击遮罩或按 `Esc` 关闭预览。

## 实现边界

- 仅修改 `video-generation.html`、`video-generation.js`、`outline.css` 以及对应前端契约测试。
- 不新增或修改数据库表、后端接口、首帧版本数据和上传逻辑。
- 为区分单击与双击，前端延迟处理单击；双击到达时取消该单击的待执行动作，避免双击产生两次选中反馈。

## 验收

1. 单击缩略图后，原有高亮选中和生成视频所用首帧不变。
2. 双击缩略图后，大图预览可见且图片不变形。
3. 三种关闭方式均可关闭预览。
4. 前端脚本语法检查和视频生成页面契约测试通过。

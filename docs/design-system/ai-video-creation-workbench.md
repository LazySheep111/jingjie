# AI 视频创作工作台 UI 规范

## 1. 设计目标

面向需要频繁查看资产、编辑分镜、发起生成与处理失败任务的创作者。界面优先级为：状态可读性、连续操作效率、信息密度、响应式可靠性。禁止营销页式大横幅、装饰渐变和无意义卡片堆叠。

设计参数：信息密度 8/10、布局变化 4/10、动效 2/10。采用浅色专业编辑器基调，单一青蓝强调色。

## 2. 视觉令牌

| 角色 | 令牌 | 用途 |
| --- | --- | --- |
| 页面背景 | `#F4F8FA` | 连续工作区背景 |
| 主表面 | `#FFFFFF` | 编辑画布、详情面板 |
| 次表面 | `#EEF6F8` | 工具栏、摘要与选中行 |
| 主文字 | `#183247` | 标题、正文、数据 |
| 次文字 | `#607889` | 说明、元数据 |
| 主操作 | `#177E9F` | 每个区域唯一主操作 |
| 成功 | `#167A57` | 已完成、可用 |
| 警告 | `#9A6517` | 排队、需要确认 |
| 错误 | `#B44343` | 失败、需修复 |
| 边界 | `#D5E4EA` | 面板与分隔线 |

圆角只使用 8px（控件）与 12px（面板）；阴影仅用于浮层和对话框。正文最小 14px、移动端最小 16px，数字/时长使用等宽数字。

## 3. 应用骨架

桌面端（>= 1200px）使用三层结构：顶部全局导航、页面级工具栏、内容工作区。内容区默认采用左侧项目/章节导航，中间主画布，右侧检查器；检查器只放只读元数据、资产预览和轻量设置，不能承载一组主要操作。

当主要操作超过两个时，放在主画布下方的全宽操作带。小于 1024px 时检查器移动到主画布之后；小于 720px 时所有区域单列，操作按钮单列且 `width: 100%`。所有 Grid/Flex 子项必须 `min-width: 0`，禁止用固定像素宽度导致横向滚动。

## 4. 核心页面模式

### 资产库

左侧为筛选与分类，中央为可缩放网格，右侧为所选资产检查器。资产卡仅显示缩略图、名称、类型、状态和最后更新时间；批量操作进入独立浮动操作条。图片固定宽高比并预留加载骨架，50 项以上使用虚拟列表。

### 分镜编辑

每个分镜是可折叠的制作单元：镜头轨道（编号、时长、景别）、脚本画布、参考资产、输出区域。生成操作固定在单元底部的全宽操作带，不放进窄侧栏。拖拽排序必须提供上移/下移按钮与键盘替代操作。

### 生成任务

任务列表按“进行中、待处理、已完成”分组。每项必须同时显示：状态文字、状态图标、任务对象、开始时间/耗时、可执行下一步。进行中提供确定进度或阶段文案；超过 1 秒显示与最终布局一致的骨架屏。

### 错误与恢复

错误在原任务位置内联展示，格式固定为“失败原因 + 建议操作 + 重试”。例如：`首帧缺失，无法生成视频。请先选择一张首帧，或重新生成首帧。`。错误色不能单独表达状态，需配合图标与文本。可重试错误提供“重试”主按钮；安全审核错误提供“安全改写后重试”；不可恢复错误提供“查看详情”与“返回分镜”。

## 5. 组件规则

| 组件 | 规则 |
| --- | --- |
| 主按钮 | 每个操作区域最多一个，青蓝实底，禁用态保留语义与原因提示 |
| 次按钮 | 白底描边，用于上传、查看历史、返回 |
| 危险按钮 | 红色描边且与主操作空间隔离，删除前确认并提供撤销 |
| 状态标签 | 文本 + 图标 + 色彩，支持换行，不截断关键状态 |
| 图标按钮 | 最小命中区 44px，必须有 `aria-label` 和 tooltip |
| 表单 | 永远有可见标签；错误位于字段下方并与字段关联 |
| 对话框 | 有关闭与 Escape 路径；打开后焦点进入对话框，关闭后回到触发控件 |

## 6. 交互与可访问性

键盘 Tab 顺序与视觉顺序一致；焦点环使用 2px 青蓝描边且不被粘性栏遮挡。正常文字对比度不低于 4.5:1，非文本控件边界不低于 3:1。所有异步状态通过 `aria-live="polite"` 汇报，不抢夺焦点。

动效只用于展开/收起、任务状态切换和反馈，150–200ms，使用 opacity/transform；`prefers-reduced-motion` 下禁用位移动效。响应式验证至少覆盖 375px、720px、1024px、1440px，任何宽度不得出现水平滚动。

## 7. 实施验收清单

- 每个页面只有一个明确主操作。
- 主操作永不位于宽度小于 320px 的侧栏。
- 资产、任务和错误均有加载、空、失败、完成状态。
- 操作按钮在 720px 以下单列全宽，最小高度 44px。
- 颜色之外始终有状态文字与图标。
- 不使用 emoji 作为系统图标；统一使用同一套 SVG 图标。
- 保存、上传、生成等异步操作禁用重复提交并给出进度或下一步说明。

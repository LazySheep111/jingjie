# 小说全文工作台入口整合设计

## 目标

移除新版导航中的“分镜脚本工作台”中转入口，把小说导入和作品选择整合进“小说全文工作台”。分镜仍保留在全文工作台的章节侧栏，视频创作仍由视频创作工作台承担。

## 用户路径

1. 用户打开“小说全文工作台”。
2. 没有已选小说时，页面显示空状态：导入 TXT/DOCX、前往历史作品选择。
3. 导入成功后，沿用 `POST /api/novel/import` 的原请求字段；将返回的 `novelId` 记录为当前小说，并进入 `novel-detail-new.html?novelId=...`。
4. 已选小说时，保留现有正文、章节、视觉风格、分镜与资产功能；页头新增次级“导入新小说”入口。
5. 用户在历史作品中改选另一部小说时，既有 `mirror:selectedNovelId` 与视频上下文清理逻辑继续生效。

## 页面职责

| 页面 | 调整后的职责 |
| --- | --- |
| 小说全文工作台 | 导入/选择作品、章节正文、分镜生成与资产操作 |
| 我的历史作品 | 浏览并切换已保存小说 |
| 视频创作工作台 | 基于已保存分镜生成首帧与视频 |
| 分镜脚本工作台 | 保留旧页面文件，不再作为新版侧栏导航入口 |

## 状态与错误处理

- 未携带且未保存 `novelId`：显示导入与历史作品选择，不显示“正在加载”。
- 文件未选择或不是 TXT/DOCX：在导入卡片内显示现有错误提示。
- 导入请求失败：保留当前空状态，在导入卡片内展示接口返回的失败原因。
- 导入进行中：禁用导入按钮并展示“正在读取小说并识别章节”。

## 兼容性边界

- 不修改后端接口、请求参数、数据库结构和上传限制。
- 不删除 `storyboard-workbench-new.html` 或旧版分镜页面。
- 保留全文页面既有元素 ID、章节编辑、分镜、资产和视频跳转逻辑。
- 新导航只移除新版“分镜脚本工作台”项；旧页面仍可通过直接 URL 访问。

## 验收标准

1. 新版侧栏不再显示“分镜脚本工作台”。
2. 未选作品的全文工作台可完成 TXT/DOCX 导入，并跳转到导入后的全文页面。
3. 已选作品的全文工作台可从页头发起新导入，且不影响既有分镜与视频功能。
4. 历史作品重新选择另一部小说后，全文和视频上下文仍遵循现有切换规则。

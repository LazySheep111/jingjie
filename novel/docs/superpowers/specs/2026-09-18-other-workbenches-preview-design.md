# 其余创作工作台新版预览设计

## 目标

为小说大纲、小说全文、历史作品、资产库、视频创作和模型管理提供独立新版预览入口。新版统一为专业创作工具界面，同时复用现有后端接口、数据格式、元素 ID 与 JavaScript 事件逻辑；任何旧页面、后端接口和数据库结构均不修改。

## 设计基调

这是高信息密度的 AI 视频创作生产工具，而不是营销页面。界面采用深石墨导航、暖白工作面、琥珀色主操作、低饱和青绿色状态提示。视觉层级以当前任务、可编辑内容、生成状态和下一步操作为先。动画仅用于聚焦和状态反馈，并支持减少动态效果。

## 新页面与信息架构

| 原页面 | 新预览入口 | 主布局 | 关键改造 |
| --- | --- | --- | --- |
| 小说大纲工作台 | `/outline-new` | 创作设定 / 大纲结果 | 表单分组、生成结果和章节大纲并置；固定生成与保存操作。 |
| 小说全文工作台 | `/novel-detail-new.html` | 章节目录 / 正文编辑 / 分镜与视觉风格 | 加宽章节和分镜列，正文保持可读行宽；将生成状态与主标题关联。 |
| 历史作品 | `/history-list-new.html` | 筛选工具栏 / 紧凑作品列表 | 一行呈现状态、章节数、更新时间和进入动作；窄屏转卡片。 |
| 资产库 | `/asset-library-new.html` | 顶部筛选 / 自适应资产网格 / 详情抽屉 | 搜索与筛选收束；详情使用右侧抽屉，不占固定大列。 |
| 视频创作工作台 | `/video-generation-new.html` | 分镜导航 / 当前镜头制作台 / 任务状态 | 首帧、脚本、视频控制同屏聚焦；失败原因和重试紧邻任务。 |
| 模型管理 | `/model-management-new.html` | 配置概览 / 三类模型配置 | 每张模型卡将测试、保存、启停和错误结果组织为连续流程。 |

## 共用约束

- 新页面加载现有 API 与业务脚本；不伪造数据。
- 保留既有元素 ID、请求参数、文件上传和弹窗行为，避免 JavaScript 兼容性回归。
- 复用现有 `workbench-shell.js` 导航壳，新增独立 CSS 以避免旧版全局样式造成布局挤压。
- 桌面端优先保证操作与状态可见；在 1200px、960px、760px 下逐级重排，任何按钮组都允许换行且不溢出。
- 状态统一分为：加载中、空状态、生成中、成功、失败、可重试；错误就近显示在对应操作之后。
- 所有新版入口保留旧页面作为回退路径；本次不替换原 URL。

## 交互与数据流

每一页只使用其原有 JavaScript 填充的区域。例如历史页的列表仍由 `history-list.js` 填充，资产库仍由 `asset-library.js` 填充，视频页仍由 `video-generation.js` 填充。新版 HTML 仅调整这些稳定挂载点的位置，新增 CSS 负责布局和状态可读性。若旧脚本没有提供某项数据，新页面只显示明确的空状态，不制造示例任务、资产或结果。

## 验证

- 每个新页面均有静态页面契约测试，验证必要 ID、脚本引用、响应式断点与旧页面隔离。
- 运行全部 `src/test/frontend` Node 测试。
- 执行 Maven 打包并确认六个静态资源进入 JAR。
- 使用本地运行服务打开每个新版地址，验证静态资源可访问；含参数页面使用已有 `novelId` 与 `chapterNum`。

# 视频创作工作台：镜头生产线设计

## 目标

将 `video-generation-new.html` 从连续堆叠的分镜表单调整为面向单镜头操作的专业生成控制台。保留现有 API、请求参数、元素选择器、任务轮询和数据格式；不改动后端接口或数据库。

## 信息架构

1. 顶部工作区头部：当前小说、章节、镜头总数，以及首帧/视频完成和失败数量；保留返回小说正文入口。
2. 镜头序列：按序号列出分镜、时长、景别和生成状态。当前镜头有明确选中态；已完成、等待首帧、生成中和失败均可一眼区分。
3. 当前镜头画布：依次展示镜头脚本、参考资产、首帧候选、当前成片和视频历史。首帧和成片区域各自拥有明确空状态。
4. 生成控制台：首帧操作与视频操作分组。视频分辨率、主操作、上传操作、失败重试与历史版本在同一侧栏中，避免与脚本争夺视觉焦点。

## 视觉与交互

- 延续新版工作台的暖灰画布、深石墨文字、橄榄状态色与琥珀主操作色。
- 当前镜头画布占主要宽度；镜头序列为紧凑导航栏；控制台宽度稳定且在桌面端保持可见。
- 首帧卡片支持选择态；视频版本历史使用可展开的紧凑列表。
- 生成中显示当前阶段；失败状态展示错误原因和“安全改写后重试”入口；空状态解释下一步需要的操作。
- 不改变现有生成、上传、选择、删除、任务轮询及版本切换事件。

## 响应式规则

- 宽屏：镜头序列 / 当前镜头 / 生成控制台三栏。
- 中等宽度：镜头序列与当前镜头两栏，控制台移至当前镜头下方。
- 窄屏：镜头序列、当前镜头、控制台依次纵向排列；所有操作按钮自动换行且保持可触达。
- 所有脚本、图片和视频媒体必须收缩于容器内，禁止页面级横向滚动。

## 验收

- 保留 `sceneList`、`pageStatus`、`pageEmpty`、首帧预览对话框和动态 `data-action` / `data-role` 元素。
- 桌面与 720px 窄屏下无横向溢出。
- 已有视频工作台前端检查继续通过。
- 不通过 UI 操作触发真实模型调用、上传、删除或生成任务。
